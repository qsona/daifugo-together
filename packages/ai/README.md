# @daifugo/ai

外部 AI API を使わない大富豪の対戦 AI です。自席の `PlayerSnapshot` と、権威エンジンが列挙した合法手だけを入力にします。

観測できない札を seed 付きで一様に再配布する決定化を使い、同じ想定 world で全合法手を1回ずつ比較します。各候補の応手は軽量ヒューリスティックで選び、全候補を評価し終えた world だけを結果へ採用します。探索は Node.js の `worker_threads` で動かし、メインイベントループを占有しません。親側の期限を超えた時点で完了済み world の統計があれば partial-search の最善手を返し、まだ1周も完了していなければ同じヒューリスティック選択へフォールバックします。

既定値は worker 1本、ライブラリ予算50/200ms、候補評価上限64、初手を含むcutoff 65手です。本番ルームは全ルール探索のためhard期限を600msに広げ、サーバーの1秒watchdogより短く保ちます。500ゲーム・26,950手番の実測では、初手から終局までの手数は中央値54、95パーセンタイル65、最大74でした。`pnpm validate:ai` は合法性・停止性と強さ・応答時間を検査し、件数は `AI_STRENGTH_SETS` と `AI_VALIDATION_GAMES` で縮小できます。

サーバー統合は `@daifugo/server` の `runAiTurn` を使います。1秒watchdog、engine fallback、探索メトリクス、0.4〜1.2秒の演出遅延を探索ライブラリの外側で扱います。

`legalPlays` が空の強制パスは、`AiDecision.play` が `Play` のみを表す契約のため、AI を呼ぶ前にゲームループ側で処理します。
