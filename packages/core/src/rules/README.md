# ルール契約 v1

正準仕様は [`docs/epics/E01-game-engine.md`](../../../../docs/epics/E01-game-engine.md) の §2.5、§2.8〜2.11、§3.5 です。

自動実装されるルールは `RuleModule` として独立登録し、状態を直接変更せず `Effect` を返します。契約 v1 では、プレイヤーへの追加入力、手の種類の追加、パス起点のフックには対応しません。

主なフックの発火点:

| フック            | 発火点                     |
| ----------------- | -------------------------- |
| `modifyLegality`  | プレイ検証・合法手列挙     |
| `modifyStrength`  | 強さ比較の直前             |
| `afterPlay`       | プレイ適用とあがり確定の後 |
| `afterFieldClear` | 場が流れた直後             |
| `onGameStart`     | 配札後、最初の手番前       |
| `onGameEnd`       | 全順位確定後               |

ルール追加時は `packages/rules/r{id}-{slug}/` の新規ディレクトリだけを変更し、型検査・単体テスト・シミュレーションを通す必要があります。
