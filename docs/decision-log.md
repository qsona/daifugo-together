# 決定台帳(みんなでつくろう 大富豪)

各 Epic 設計書の §5(未決事項・Epic 間連絡・修正提案)に散在している「まだ決まっていないこと」を 1 か所に集めた台帳。**実装エージェントは、ストーリー着手時にこの台帳の「宛先」欄で自分のストーリー ID を検索し、該当する決定を先に片付けてから作業を始めること。**

- 作成: 2026-07-25
- 状態値: `未決`(誰かの決定待ち) / `決定済み`(決定内容を併記。設計書側への反映が済んでいなければ「反映待ち」と付す) / `保留`(今は決めない。トリガー条件を併記)
- **決定したら**: この台帳の状態を更新し、該当設計書の当該箇所も更新する(台帳と設計書が食い違ったら**設計書を正**とし、台帳を直す)
