# 管理ダッシュボードの24時間集計・ゲーム数推移

- 日付: 2026-08-12 / 状態: 完了
- 関連: [管理画面 runbook](../runbooks/admin-console.md)

## 1. 背景と目的 [変更不可]

管理画面の短期利用状況を、日付境界に左右されない直近24時間で確認できるようにする。あわせて、ゲーム数の中期的な増減を直近14日で把握できるようにする。

## 2. ユーザー体験 [変更不可]

- 概要上部の期間カードを「直近30分」「直近3時間」「直近24時間」とする。
- 概要画面に、直近14日間のゲーム数推移を見やすいグラフまたは表で表示する。

## 3. 受け入れ条件 [変更不可]

1. 既存の「本日（JST）」期間カードが「直近24時間」に置き換わり、各指標が現在時刻から遡った24時間で集計される。
2. 今日を含む直近14日について、日別ゲーム数の推移を管理画面で確認できる。
3. ゲームがない日も0件として表示される。
4. 375×812の画面で横方向のページはみ出しなく閲覧できる。

## 4. スコープ外 [変更不可]

- 管理画面以外の運用ダッシュボードの表示変更
- 日付範囲の任意選択やCSV出力

## 5. 詳細仕様 [変更可・記録必須]

- 14日推移の日付境界はJSTとし、今日を含む14暦日を対象にする。
- 日別ゲーム数は、その日に終了した卓の `game_sets.games_played` の合計とする。
- 当日は途中時点の値であることを画面上に示す。

## 6. 技術設計メモ [参考]

- `/admin/api/overview` のレスポンスへ日別推移を追加する。
- グラフは追加ライブラリに依存せず、管理画面内のHTML/CSS/SVGで描画する。
