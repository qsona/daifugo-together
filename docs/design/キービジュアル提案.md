# ラウンド 2(2026-07-24)— 縦長・全年齢トーン

## 開発者フィードバックの要約(ラウンド 1 に対して)

1. キャッチコピーは、旧案B の SVG 内コピー**「毎日どこかで、新ルール。」が最も良い**。→ その後、企画書 §6 で**正式採用が確定**した(理想状態を言い切るブランドコピーであり、実装頻度の運用制限と矛盾しない、という整理)。
2. ポップの方向性は思っていたものにかなり近い。ただし**やや子供っぽすぎる**。
3. ターゲットは老若男女。桃太郎電鉄(またはそれに近い家庭用ゲーム)のような「**子供がメインターゲットではありつつ、大人も普通に楽しむ**」水準にしたい(企画書 §2.3 に反映済み)。
4. スマホメインなので、**タイトル画面として使える縦長**が欲しい(企画書 §6 で縦長 9:16 基本が確定)。

## 開発者決定(2026-07-24)

**案2A「グランドフェス」を UI 展開の基準として採用。** あわせて開発者指示の調整 3 点を key-visual-2a.svg に適用済み:

1. ロゴ「大富豪」をラウンド 1 案A の意匠(1 文字ごとの赤・黄・緑)で塗り分け。ただしトーンはラウンド 2 水準を維持し、色値は深め・高コントラストの調整方針に合わせた(大 #E14B3B / 富 #FFC53D / 豪 #2FA36B。直立・クリーム縁・紺縁・ベタ落ち影の構造は変更なし)。
2. タップ導線の文言を「タップしてはじめる」(全角スペース除去)に変更。ピル幅も 640→600px に詰めてバランスを調整。
3. 下部キャラクターの発言(吹き出し「革命!!」「ピッ!!」、掲げ札「ぜんぶ8」)を削除。道化・審判のキャラクター自体は残し、空きを補うため 2 体を 1.12 倍に拡大(位置は微調整のみ)。

## 補足: 企画書 §4.1 の更新との整合(2026-07-24)

本ラウンド**着手後**に企画書 §4.1 が更新され、「都道府県は提案者がその土地で遊んでいた**出自の記録**であり、ルールの分布実態を示すものではない。『〜県のルール』と断定する見せ方はしない」が確定した。これを受けて、SVG 内の都道府県表記を「◯◯発」(新潟発 など)に修正し、断定の読みを画面上でも解消した。なお案2B の千社札は、本来「貼った人の名・出身を書いて貼る札」であり、都道府県表記を「ルールの産地」ではなく「提案者の出自」として読ませる意図のモチーフ選択である(詳細は案2B の節)。

**追記(2026-07-28・開発者指示)**: 採用案 2A の手札のルールカードから、都道府県表記「新潟発」と通し番号「No.148」、および「NEW」の小さい文字をすべて削除した。理由は 2 つ。(1) 「新潟発」は 8切りの出自を示す根拠がなく、出自の記録としても裏付けがない表示になる。(2) 扇状に重なる手札では小さい文字が隣の札に隠れて見切れる(No.148 が実際に欠けていた)。ルールカードは「革命」「8切り」の名前だけを縦組みで見せ、削除した分は 2〜3 文字を札の中央に寄せ直して余白を埋めている。案2B 以降の未採用案は提案時の記録として現状のまま残す。

## トーン調整の方針 — 何を変えたか

「ポップは維持、子供っぽさを一段抜く」を次の 5 点に分解して全案に適用した。参照先である桃太郎電鉄の絵作りは「賑やかだが造形は大人の漫画的カリカチュア」であり、幼児向けのゆるかわではない——そこを目標水準に置いた(固有キャラ・ロゴ・固有造形の模倣はしない)。

1. **タイポグラフィ主導に転換**: ラウンド 1 でロゴ各文字に付けていた ±3〜6° の傾きを全廃。「大富豪」は直立の極太文字組み+多層の縁・ベタ落ち影で「構造のしっかりした」ロゴにした。傾き・遊びはリボン・札・スタンプなど少数の脇役に限定して効かせる。
2. **顔の文法を変更**: 頬の丸+点目+小さな笑み、というゆるかわ文法を廃止。**眉を追加**し、ニヤリ(道化)・きりり(審判)・大笑い(カードキャラ)といった芝居のある表情にした。2A ではカードを擬人化せず「本物のトランプ」として描き、キャラは人型 2 人に絞った。
3. **パレットに深みとコントラスト**: パステル寄りの地色(水色 #59C9EF 等)をやめ、深い青 #2B6FC2・生成りクリーム #F5EBD3・夜紺 #0D1330 と、値の締まった地色に変更。アクセントも彩度を保ったまま明度を一段下げた(例: ピンク #FF7BAC → マゼンタ #D63B78、黄 #FFD84D → 金 #FFC53D)。
4. **密度の規律**: ラウンド 1 で最も大人に振れていた旧案B のグラフィック的規律(整列・枠・帯)を 3 案すべてに導入。紙吹雪・吹き出しの数を大きく絞り、祝祭感は万国旗・引き幕・ネオンなど「大人も知っている祭りの記号」で出す。
5. **過剰修正はしない**: フィードバックは「ポップは近い」と言っているため、シック・コーポレート方向には振らない。高彩度アクセント・太い輪郭線・コミカルな芝居は 3 案とも維持した。

## 案2A「グランドフェス」

**ひとことコンセプト**: 昼の祝祭を正面ステージ構図で。旧案A の祝祭感 × 旧案B の規律。

**子供っぽさをどう抜いたか**
- ロゴを直立・多層縁(1 文字ごとの赤・黄・緑 + クリーム縁 + 紺縁 + ベタ落ち影)の構造的な文字組みに変更。塗り分けはラウンド 1 案A の意匠を、深めの色値(#E14B3B / #FFC53D / #2FA36B)で引き継いだもの(開発者決定)。傾きはキャッチコピーのリボン(-1.5°)と手札の扇だけに限定。
- 手札のカードは擬人化せず「本物のトランプ」。ゆるかわ顔のカードキャラを全廃し、キャラは**道化(いたずらな提案者)と審判**の人型 2 人だけに絞った。どちらも眉つきの芝居顔(ニヤリ/きりり)。発言の吹き出しは開発者決定で削除し、ポーズだけで芝居を読ませる。
- 紙吹雪をラウンド 1 の 20 個から 8 個に削減し、空を深い青 #2B6FC2 に。放射光線は残して祝祭感を維持。

**タイトル画面としての設計(ロゴ/コピー/タップ導線)**
- 上 1/3: 万国旗ガーランド(y≈150 以深に配置しステータスバーを回避)→「みんなでつくろう」→ 直立の「大富豪」。サムネイルでもロゴが最初に読める中央上段配置。
- 中段: キャッチコピーを赤リボンで独立させ、ロゴ直下の視線の受け皿にする。
- 下 1/3: **ルールカード(NEW RULE「革命」/ LOCAL RULE「8切り」新潟発)が混ざった手札の扇**。「普通の大富豪にユーザー発のルールが混ざり込む」というゲーム内容の説明を、タイトル画面の絵で先に済ませる。手札の後ろで道化と審判が小競り合いし(道化は腕を振り上げ、審判はイエローカードを掲げる)、カオスと秩序の関係をポーズだけで見せる。

**ゲーム内 UI への展開**
- 色面のルールカード(NEW RULE = 金 / LOCAL RULE = 緑)は、そのままルール図鑑(§4.5)のカード部品になる。
- リボン=見出し部品、審判=イエローカード通知(§5.2)のキャラクター。ルール発動の吹き出しはゲーム内演出の部品として引き続き有効(タイトル画面上の発言吹き出しは開発者決定で削除)。
- 手札の扇はゲーム画面の手札 UI の先取りで、タイトル→対局の画面連続性が高い。

**リスク**: 3 案では依然いちばん情報量が多い。実装時は背景の光線・紙吹雪を間引く運用が必要。

## 案2B「ルール番付」

**ひとことコンセプト**: 番付×千社札×引き幕の和モダン印刷。旧案B の縦組み進化形で、縦長フォーマットを最も活かす案。

**子供っぽさをどう抜いたか**
- キャラクターを使わない。タイポグラフィ・罫線・紋だけで構成する 3 案中もっとも大人側の案。
- 「大富豪」を**縦一列の縦組み**(番付の看板文字の文法)にし、朱の版ズレで印刷物の重みを出す。傾きは千社札(±2〜3°)とスタンプ(-12°)のみ。
- スートをそのまま散らさず**家紋(丸に紋)として意匠化**。縦の欧文キャプション(DAIFUGO —)で現代のポスター感を足し、駄菓子屋レトロが幼児向けに転ばないよう調整。
- 祝祭感は上端の**引き幕ストライプ**(芝居小屋の記号)で出す。

|---|---|

| #26364D | ネイビー(ロゴ・枠・本文) |
| #D9432F | 朱(版ズレ・スタンプ・千社札ヘッダ) |

| #FFFBF0 | オフホワイト(千社札・コピー面・切符) |

**タイトル画面としての設計(ロゴ/コピー/タップ導線)**
- 全体を二重の印刷枠で囲い、上端に引き幕 → 屋号プレート「みんなでつくろう」→ 中央に縦組み「大富豪」。
- ロゴの左右に**千社札化したローカルルール**(新潟発「8切り」/東京発「都落ち」/全国「革命」/千葉発「しばり」)を貼る。ローカルルールの出自の記録(§4.1: 提案者がその土地で遊んでいたという記録であり、分布実態の断定ではない)を縦長の余白で立たせる、この案の主役ギミック。千社札はもともと「貼った人の名・出身を書く札」なので、都道府県=提案者の出自という §4.1 の整理とモチーフの意味が一致する。ヘッダも「◯◯発」表記で断定を避けている。
- ロゴ末尾に「ルール増殖中」スタンプを重ね押しし、静的な紙面に「増えていく」動きを足す。
- キャッチコピーは中央下の白プレートに最大級の扱いで置き、その下にスート家紋列 → **切符型の「タップして はじめる」**(START の半券つき)→ ティール帯「あなたの街のローカルルール、募集中です。」で締める。この最下部の帯は**装飾扱いで重要要素ではない**(下 6% の安全帯に一部かかるが、切符ボタンとの間隔を保つため現位置とした。実装時は削除または上移動してよい)。

**ゲーム内 UI への展開**
- 千社札=ルール図鑑のリスト部品(出自ヘッダ+ルール名のレイアウトが既に載っている)。UI 化する際も §4.1 に従い「◯◯発」「◯◯で遊ばれていた報告」のような断定しない見せ方にする。
- スタンプ=採用/排除(§4.4)の演出。切符=ボタンの文法。色数 6 で UI への落とし込みは 3 案中最も簡単。

**リスク**: 動きのあるキャラがいないぶん、初見の「わちゃわちゃ楽しそう」は 2A・2C に譲る。カオスはスタンプと札の増殖で読ませる設計。

**ゲーム内 UI への展開**
- ダークテーマ UI に直結(長時間対局で目に優しい)。
- 「道が 1 マス伸びる」=ルール採用演出、ネオン看板=新ルール告知、キャラの行進=ローディング/待機アニメーション。
- 明るいテーマも作る場合は配色の再設計が必要(旧案C と同じ注意点)。

**リスク**: 夜=ダーク基調は「ポップ=明るい昼」の期待に対しては変化球。ストア画像などで 2A 系の昼絵と並べると効果的。

## 推薦案(ラウンド 2)— 決定済み

**ステータス: 決定済み。** 開発者が案2A「グランドフェス」を UI 展開の基準として採用した(「開発者決定(2026-07-24)」節参照)。以下は決定前の推薦理由の記録である。

**案2A「グランドフェス」を推す。** 理由:

1. フィードバックの「ポップはかなり近い、子供っぽさだけ抜きたい」に対する最短距離の答えであり、昼の祝祭感(旧案A)を保ったまま造形だけを大人側に寄せている。
2. ルールカードが混ざった手札の絵で、ゲームの説明が 0.5 秒で終わる。タイトル→対局画面への UI 連続性も 3 案で最も高い。
3. 2B は「どこまで大人に振ってよいか」の上限見本、2C は中間+キャラ IP 路線の見本として機能する。トーンの当たり判定は 2B(最も大人)→ 2C(中間)→ 2A(祝祭寄り)の軸で比較できるように 3 案を設計した。

ただし、ローカルルールの出自(◯◯発、§4.1)をブランドの核に立てるなら 2B、キャラクターと世界観で覚えてもらうなら 2C に十分な合理性がある。**最終決定は開発者に委ねる**。折衷案(2A の構図に 2B の千社札/切符部品を UI として取り込む等)も現実的。

## 案A「カードまつり」

**ひとことコンセプト**: ルールが飛び交うお祭り会場。全部乗せの王道ポップ。

**狙い(企画書のどの要素を引き受けるか)**
- 「わちゃわちゃしたカオスをみんなで笑う」(§1, §2.2)を画面の密度そのもので表現する。放射光線・紙吹雪・飛び交うカードで「常に何かが起きている」状態を見せる。
- ルール名の吹き出し(8切り・都落ち・革命・11バック)で「ルールが増えていくゲーム」だと一目で伝える。
- イエローカードを掲げる審判(§5.2)を初期画面から登場させ、インジェクション対策の世界観演出を最初から公式キャラ化する。
- 左上の「新ルール ぞくぞく増殖中!」バッジは、実装済みルール数の増加(§11 成功指標)を告知する枠としてそのまま UI 化できる。

**カラーパレット**

| Hex | 役割 |
|---|---|
| #59C9EF | ベース(空) |
| #7FD8F5 | 放射光線 |
| #FF6B6B | 赤アクセント(ハート・ロゴ・リボン) |
| #FFD84D | 黄(イエローカード・ロゴ・バッジ) |
| #58C48A | 緑(丘・クラブ・ロゴ) |

補助色: #FF9EDB(紙吹雪)、#FF9F45(ダイヤ)、#E8503A(リボン折り返し)。

**ロゴ・文字の扱い**: 「大富豪」を 1 文字ずつ赤・黄・緑に塗り分け、白縁+紺縁の二重縁取りで背景から浮かせる。各文字に ±3〜6° の傾きを付けて祭りの浮かれた感じを出す。上段「みんなでつくろう」は白抜き+紺縁。ロゴ直下に「ルールは きみが つくる!」のリボンでコンセプトを言い切る。

**ゲーム内 UI への展開方針**
- ボタン: 白面+紺の太輪郭+角丸(カードキャラと同じ文法)。押下時に軽く傾ける。
- ルール発動演出: 本案の吹き出しをそのまま流用(発動したルール名が吹き出しで飛び出す)。
- 警告系: 審判+イエローカードを通知トーストのキャラクターにする。
- 色運用: 空色を地、赤=アクション、黄=注意・強調、緑=成功と役割を固定すれば、色数が多くても破綻しない。

**向いている読者/リスク**: パーティゲームらしさを最優先したい場合の第一候補。ローカルルール文化で盛り上がった層(§2.3)に最も刺さりやすい。リスクは要素密度が高く、実装時に画面情報と喧嘩しやすいこと。ゲーム UI に載せる際は背景要素を間引く運用が必要。

## 案B「レトロポップ印刷」

**ひとことコンセプト**: 昭和の駄菓子屋ポスター×切符。ローカルルールを「地元の名産」として掲示する。

**狙い(企画書のどの要素を引き受けるか)**
- ローカルルール×都道府県(§4.1)を最も強く引き受ける案。「ローカルルール急行 新潟 発 → 全国 行」の切符モチーフで、「地元のルールが全国区になる」というゲームの資産価値を絵にする。
- 「大富豪 = 昔からみんなで改造してきたゲーム」(§2.1)という文化的な文脈を、レトロ印刷の風合い(版ズレ・ハーフトーンドット・スタンプ)で表現する。
- 「ルール増殖中」スタンプと下端の「ローカルルール、募集中です。」帯で、提案機能への導線を画面のコピーとして常設する。

SVG 内のコピー「毎日どこかで、新ルール。」は、提案時点では運用実態(§4.2 の提案キュー・実装頻度制限)に対する願望的表現と注記していたが、**その後開発者に選ばれ、企画書 §6 で正式採用された**(理想状態を言い切るブランドコピーという位置づけ)。

**カラーパレット**

|---|---|
| #F6EEDC | ベース(クリーム地) |
| #27374D | ネイビー(本文・輪郭・ロゴ本体) |
| #E8503A | 朱(版ズレ・スタンプ・ハート) |
| #2E9E8F | ティール(帯・サブ情報) |

**ロゴ・文字の扱い**: 「大富豪」はネイビーのベタ文字に朱の版ズレ(右下 12px オフセット)を敷く。縁取りなし・傾きなしの直立で、A・C と正反対の「静かに構えた」ロゴ。「みんなでつくろう」はティール帯に白抜き。

**ゲーム内 UI への展開方針**
- ルール一覧: 切符型カードをそのまま UI コンポーネント化(ルール番号・ルール名・発祥都道府県のレイアウトが既に載っている)。都道府県の項目が UI 上の一級市民になる。

- 色数が 6 色と少なく、Web UI への落とし込みが最も簡単。文字の可読性も 3 案で最良。
- イエローカード演出は朱+マスタードの範囲で追加可能。

**向いている読者/リスク**: 「AI がゲームを自動改造する」仕組みに興味を持つ個人開発・AI 界隈の層(§2.3)には、この抑制の効いたデザインの方が「わかってる感」を出せる。リスクは 3 案の中で最も静的で、「カオスで楽しい」感が弱いこと。カオスは絵ではなくコピーと切符の増殖で表現しているため、初見のパーティ感は A・C に劣る。

## 推薦案(ラウンド 1 時点)

**案A「カードまつり」を推す。** 理由は次の 3 点。

1. 企画の一番の売りである「カオスをみんなで笑う」(§1)を、説明なしの 0.5 秒で伝えられるのは A だけ。B はコピーを読ませて伝わり、C はシーンを読み取って伝わる。開始画面は滞在時間が短いため、即読性を最優先した。
2. イエローカードの審判(§5.2)・ルール増加の告知枠・ルール名吹き出しと、フェーズ 2 以降に必要になる演出部品が最初から画面内に揃っており、キービジュアルがそのまま UI 部品カタログを兼ねる。
3. 「ポップな感じ、イメージは桃太郎電鉄」(§6)という確定方針に対して、昼の高彩度・お祭り構図の A が最も素直に応える。

ただし、ローカルルールの地域性を初期からブランドの核にしたいなら B、キャラクター IP として育てたいなら C にも十分な合理性がある。ターゲットのどちら(§2.3 の 2 層)を先に取りに行くかで判断が変わるため、**最終決定は開発者に委ねる**。折衷として「A をベースに、B の切符型ルールカードを UI 部品として取り込む」構成も現実的。
