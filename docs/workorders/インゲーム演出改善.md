# 発注書: インゲーム演出改善 実装計画(2026-07-30)

> **エージェント向け:** 本計画は superpowers:subagent-driven-development(推奨)または superpowers:executing-plans でタスク単位に実装すること。各ステップは `- [ ]` のチェックボックスで進捗を追う。
>
> 進め方の共通ルールは [implementation-workorder.md](../implementation-workorder.md) を参照。

**ゴール:** 対局中の「何が起きたか」を読み取れるようにする。カットインが引いてから場が流れる / ルール名タップで盤面を離れずモーダルが開く / 自分の手番が手札トレイで分かる。

**設計書:** [docs/design/インゲーム演出改善設計.md](../design/インゲーム演出改善設計.md) が正。本書は設計書を実装手順に落としたもので、仕様の判断が要る場面は設計書へ戻ること。

**アーキテクチャ:** サーバーは by-id の図鑑エンドポイントを 1 本足すだけ(`GET /api/rules/{ruleId}`)。`@daifugo/core` の**部屋の契約(`PlayerRoomView` / `RuleRef`)は変更しない**。Web 側は、卓の描画ロジックを `App.tsx` から `src/game/table.ts` へ切り出して単体テスト可能にし、そこに「場が流れるのを保持する」モードを足す。モーダルは既存 `Dialog` を拡張して 2 種類(有効ルール一覧・ルール詳細)を組む。

**技術スタック:** TypeScript 6.0.3 / Node.js 26 / pnpm 11.17.0 / React 19 / Vitest 4 + @testing-library/react / CSS Modules + `docs/design/design-tokens.css` のトークン

## 全体制約

- **`@daifugo/core` の `PlayerRoomView`・`RuleRef` は変更しない。** 説明文は by-id の図鑑 API から取る。
- 色は必ず `design-tokens.css` のトークン変数を使う。生の hex を書かない(`pnpm lint:design` が落ちる)。
- 状態を**色だけ**で表さない。必ず文字か形を添える。
- `prefers-reduced-motion: reduce` では新しい動きをすべて止める。
- 文字を `opacity` で透過させない(decision-log G-7)。沈めるときは面と枠の色を変える。
- 対局・待機画面では人気度・都道府県・優先度の**数値**を出さない(企画書 §4.5)。
- テストコメント・UI 文言は日本語。既存ファイルの語彙とトーンに合わせる。
- 検証コマンドは `pnpm verify`(format:check → lint → lint:design → typecheck → test → build)。タスク単位では `pnpm vitest run <path>` で足りる。
- `docs/` は Prettier の対象外(decision-log G-3)。

```ts
import type { RuleCatalogItem, RuleCatalogResponse } from '@daifugo/core';

import type { RuleCatalogQuery, RuleCatalogResult } from './repository.js';

/** 一覧の 1 件と同じ形。by-id もこれを受け取る。 */
export type RuleCatalogEntry = RuleCatalogResult['items'][number];

export interface RuleCatalogPort {
  catalog(query: RuleCatalogQuery): RuleCatalogResult;
  catalogItem(ruleId: string): RuleCatalogEntry | null;
}

type CatalogHttpResult =
  | { status: 200; body: RuleCatalogResponse }
  | { status: 400; body: { error: 'invalid_query'; field: string } };

type CatalogDetailHttpResult =
  | { status: 200; body: RuleCatalogItem }
  | { status: 404; body: { error: 'rule_not_found' } };
```

`RuleCatalogService` クラスに次の 2 つを足し、`list()` の `items:` を `result.items.map((rule) => this.#item(rule))` に置き換える。

```ts
  detail(ruleId: string): CatalogDetailHttpResult {
    const rule = this.#rules.catalogItem(ruleId);
    // disabled は未公開。存在しない扱いにする。
    if (!rule || (rule.status !== 'active' && rule.status !== 'removed')) {
      return { status: 404, body: { error: 'rule_not_found' } };
    }
    return { status: 200, body: this.#item(rule) };
  }

  #item(rule: RuleCatalogEntry): RuleCatalogItem {
    return {
      id: rule.id,
      name: rule.name,
      description: rule.description,
      kind: rule.kind,
      prefecture: rule.prefecture,
      status: rule.status as 'active' | 'removed',
      priority: this.#priorityEnabled ? rule.priorityRank : null,
      popularity: this.#popularityEnabled
        ? Math.round(rule.popularityScore * 100)
        : null,
      implementedAt: new Date(rule.createdAt).toISOString(),
      removedAt:
        rule.status === 'removed' ? new Date(rule.updatedAt).toISOString() : null,
    };
  }
```

```ts
/**
 * 直近のプレイより後ろに fieldCleared があるか。
 * カットインの再生中はここが真のあいだ場の札を残し、
 * カットインが引いてから流す(設計書 §1)。
 */
export function hasPendingFieldClear(room: PlayerRoomView): boolean {
  const history = room.game?.history ?? [];
  const lastPlayed = history.findLastIndex((event) => event.t === 'played');
  if (lastPlayed < 0) return false;
  return history
    .slice(lastPlayed + 1)
    .some((event) => event.t === 'fieldCleared');
}

export function tableSeats(
  room: PlayerRoomView,
  options: { keepClearedField?: boolean } = {},
): TableSeat[] {
  const game = room.game;
  if (!game || room.you.seatId === null) return [];
  // 保持中は「直近のプレイより後ろの fieldCleared」だけを無視する。
  // それより前の fieldCleared(前の場の終わり)は今までどおり効かせる。
  const ignoreFrom =
    options.keepClearedField && hasPendingFieldClear(room)
      ? game.history.findLastIndex((event) => event.t === 'played')
      : Number.POSITIVE_INFINITY;
  const plays = new Map<number, CardView[][]>();
  for (const [index, event] of game.history.entries()) {
    if (event.t === 'gameStarted') {
      plays.clear();
    } else if (event.t === 'fieldCleared') {
      if (index < ignoreFrom) plays.clear();
    } else if (event.t === 'played') {
      plays.set(event.seat, [
        ...(plays.get(event.seat) ?? []),
        cards(event.cards),
      ]);
    }
  }
  // …以降は移設前と同じ(finished / bySeat / return の組み立て)
}
```

```tsx
  title: string;
  visual?: ReactNode;
  children: ReactNode;
  actions?: ReactNode;
  disableAnimation?: boolean;
  /** 閉じられるモーダルにする。渡すと閉じるボタン・スクリム・Esc が効く。 */
  onClose?: () => void;
  /** 一覧のように縦に伸びる中身は wide にする。 */
  size?: 'compact' | 'wide';
  align?: 'center' | 'start';

export function Dialog({
  title,
  visual,
  children,
  actions,
  disableAnimation = false,
  onClose,
  size = 'compact',
  align = 'center',
}: DialogProps) {

    if (!onClose) return;
    const onKeyDown = (event: KeyboardEvent) => {
      if (event.key === 'Escape') onClose();
    };

    return () => {

    };

  return (

      onClick={onClose ? () => onClose() : undefined}

      <div
        className={cx(
          styles.dialog,
          disableAnimation && styles.noAnimation,
          size === 'wide' && styles.wide,
          align === 'start' && styles.alignStart,
        )}
        role="dialog"
        aria-modal="true"
        aria-labelledby={titleId}
        data-animation={disableAnimation ? 'off' : 'on'}
        onClick={(event) => {
          event.stopPropagation();
        }}
      >
        {onClose && (

            type="button"
            className={styles.close}
            aria-label="閉じる"
            onClick={onClose}
          >

          </button>
        )}

        <h2 id={titleId} className={styles.title}>

        </h2>
```

```tsx
import type { RuleCatalogItem } from '@daifugo/core';
import { useEffect, useRef, useState } from 'react';

import type { RuleCatalogApi } from '../rules/client';
import { ruleOriginLabel } from '../rules/origin';

import { Button } from './Button';
import { Dialog } from './Dialog';
import { Tag } from './Tag';
import styles from './RuleDetailModal.module.css';

/**
 * 発動したルール 1 件の詳細。対局中に開くので、名前は即座に出し、
 * 説明文だけ図鑑 API の応答で後追いに差し込む(設計書 §2.2)。
 */
export function RuleDetailModal({
  api,
  ruleId,
  name,
  effectLabel,
  onClose,
}: {
  api: RuleCatalogApi;
  ruleId: string;
  name: string;
  effectLabel?: string;
  onClose: () => void;
}) {
  const [rule, setRule] = useState<RuleCatalogItem | null>(null);
  const [failed, setFailed] = useState(false);
  const [attempt, setAttempt] = useState(0);
  const requestSequence = useRef(0);

  useEffect(() => {
    const requestId = ++requestSequence.current;
    setFailed(false);
    void api.get(ruleId).then(
      (loaded) => {
        if (requestId === requestSequence.current) setRule(loaded);
      },
      () => {
        if (requestId === requestSequence.current) setFailed(true);
      },
    );
  }, [api, attempt, ruleId]);

  const origin = rule ? ruleOriginLabel(rule.kind, rule.prefecture) : null;
  return (
    <Dialog title={name} align="start" onClose={onClose}>
      {origin && (
        <p className={styles.meta}>
          <Tag variant={rule?.prefecture ? 'pref' : (rule?.kind ?? 'local')}>
            {origin.badge}
          </Tag>
        </p>
      )}
      {effectLabel && <p className={styles.effect}>{effectLabel}</p>}
      {rule?.description && (
        <p className={styles.description}>{rule.description}</p>
      )}
      {failed && (
        <p className={styles.failed} role="alert">
          説明を読み込めませんでした
          <Button
            size="small"
            onClick={() => {
              setAttempt((count) => count + 1);
            }}
          >
            もう一度ためす
          </Button>
        </p>
      )}
    </Dialog>
  );
}
```

```ts
export type RoomRoute = {
  roomId: string;
  view:
    'waiting' | 'game' | 'game-result' | 'set-result' | 'rules' | 'rule-dex';
  /** view が 'rules' のときだけ。ルール詳細モーダルを開く。 */
  ruleId?: string;
};
```

```ts
export function parseRoomRoute(pathname: string): RoomRoute | null {
  const match =
    /^\/rooms\/([^/]+)\/(waiting|game|game-result|set-result|rules|rule-dex)(?:\/([^/]+))?\/?$/.exec(
      pathname,
    );
  if (!match) return null;
  // ruleId を取れるのは rules だけ。ほかの view の余計なセグメントは不正扱いにする。
  if (match[3] !== undefined && match[2] !== 'rules') return null;
  try {
    return {
      roomId: decodeURIComponent(match[1]!),
      view: match[2] as RoomRoute['view'],
      ...(match[3] === undefined
        ? {}
        : { ruleId: decodeURIComponent(match[3]) }),
    };
  } catch {
    return null;
  }
}
```
